# WOMB TO TOMB 🎯

## Basic Details
### Team Name: Blooms

### Team Members
- Member 1: Fathima Rifvana
- Member 2: haneena thasni

### Project Description
WOMB TO TOMB is an interactive web-based life simulation game where every single choice you make—from baby diaper changes and toddler snacks to school habits and adult fitness—dynamically sculpts your cartoon avatar's physical appearance, posture, and life progression from birth to old age.

### The Problem (that doesn't exist)
People live their whole lives making questionable daily choices—like eating 5 lollipops for lunch or playing mobile games all night—without immediately seeing their body transform into a hunched, 45-degree bent, bald, 6-pack-less character in real time.

### The Solution (that nobody asked for)
A hilarious, highly dynamic 2D cartoon life simulator that visually punishes or rewards your choices instantly: refuse to change a baby's diaper and they grow up lean with black facial dots; eat fast food at age 9 and you turn chubby with double chins at age 12; live a 100% healthy lifestyle and unlock a gym trainer 6-pack body with a full head of hair!

## Technical Details
### Technologies/Components Used
For Software:
- HTML5 (Semantic Game Layout & Canvas Containers)
- Vanilla CSS3 (Custom Design Token System, Glassmorphism, Responsive Animations)
- JavaScript ES6 (Dynamic SVG Character Rendering Engine, State Management, Event Handlers)
- SVG Graphics Engine (Procedural Cartoon Character & Expression Generator)
- Git & GitHub (Version Control & Collaboration)
- Vercel (Production Web Hosting & Deployment)
